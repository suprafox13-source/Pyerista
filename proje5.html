Mesafe Sensörü Projesi

Açıklama

Ultrasonik sensör ile cisimlerin uzaklığı ölçülür ve seri ekranda gösterilir.

Bağlantılar

  • VCC → 5V
  • GND → GND
  • Trig → 9
  • Echo → 10

Malzemeler

  • Arduino Uno
  • HC-SR04
  • Jumper Kablolar

Kodlar

int trig = 9;
int echo = 10;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long sure = pulseIn(echo, HIGH);
  long mesafe = sure / 58;

  Serial.println(mesafe);
  delay(500);
}
