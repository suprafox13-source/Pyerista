Pyerista – Arduino Projeleri

💡 Blink (LED Yakıp Söndürme)

Ardunionun en basit projesi LED yakıp söndürme.

Açıklama

Bu proje Arduino ile LED kontrolünü öğretir.

Kod

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

🚦 Trafik Lambası (Arduino)

Arduino ile 3 LED kullanılarak yapılan trafik lambası projesi.

Açıklama

Bu proje zamanlama ve çoklu LED kontrolünü öğretir.

Kod

int kirmizi = 8;
int sari = 9;
int yesil = 10;

void setup() {
  pinMode(kirmizi, OUTPUT);
  pinMode(sari, OUTPUT);
  pinMode(yesil, OUTPUT);
}

void loop() {
  digitalWrite(kirmizi, HIGH);
  delay(5000);
  digitalWrite(kirmizi, LOW);

  digitalWrite(sari, HIGH);
  delay(2000);
  digitalWrite(sari, LOW);

  digitalWrite(yesil, HIGH);
  delay(5000);
  digitalWrite(yesil, LOW);
}
