Blink (LED Yakıp Söndürme)

Açıklama

Arduino’nun en basit projesi LED yakıp söndürmedir. Bu projede dijital pin kullanımı ve delay mantığı öğrenilir.

Arduino Kodu


void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Bağlantılar

  • LED → 13. pin
  • 220Ω direnç
  • GND → eksi (-)
