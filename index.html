Blink (LED Yakıp Söndürme)

Açıklama

Bu proje Arduino ile bir LED’in belirli aralıklarla yakılıp söndürülmesini gösterir.

Malzemeler

  • Arduino Uno
  • LED
  • 220Ω direnç
  • Breadboard
  • Jumper kablolar

Bağlantılar

  • LED (+) → 13. pin
  • LED (−) → GND

Kodlar

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
