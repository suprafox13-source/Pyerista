Blink (LED Yakıp Söndürme)

Arduino’nun en basit projesi: LED yakıp söndürme.

Bağlantılar

  • LED → 13. pin
  • 220Ω direnç
  • GND → eksi (-)

Kodlar

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
