Blink (LED Yakıp Söndürme)

Ardunionun en basit projesidir. LED belirli aralıklarla yakılıp söndürülür.

Malzemeler

  • Arduino Uno
  • LED
  • 220Ω direnç
  • Breadboard
  • Jumper kablolar
void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Trafik Lambası

Kırmızı, sarı ve yeşil LED’lerin sırayla yandığı trafik lambası simülasyonu.

Malzemeler

  • Arduino Uno
  • 3 LED (Kırmızı, Sarı, Yeşil)
  • 3 adet 220Ω direnç
  • Breadboard
  • Jumper kablolar
int k=8, s=9, y=10;
void setup(){
  pinMode(k,OUTPUT);
  pinMode(s,OUTPUT);
  pinMode(y,OUTPUT);
}
void loop(){
  digitalWrite(k,1); delay(3000); digitalWrite(k,0);
  digitalWrite(s,1); delay(1000); digitalWrite(s,0);
  digitalWrite(y,1); delay(3000); digitalWrite(y,0);
}
