Blink (LED Yakıp Söndürme)

Ardunionun en basit projesidir. Bu projede bir LED belirli aralıklarla yakılıp söndürülür.

Malzemeler

  • Arduino Uno
  • 1 adet LED
  • 220Ω direnç
  • Breadboard
  • Jumper kablolar

Kodlar

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Trafik Lambası

Arduino ile trafik lambası simülasyonu. Kırmızı, sarı ve yeşil LED’ler sırayla yanar.

Malzemeler

  • Arduino Uno
  • 3 adet LED (Kırmızı, Sarı, Yeşil)
  • 3 adet 220Ω direnç
  • Breadboard
  • Jumper kablolar

Kodlar

int k=8, s=9, y=10;

void setup() {
  pinMode(k, OUTPUT);
  pinMode(s, OUTPUT);
  pinMode(y, OUTPUT);
}

void loop() {
  digitalWrite(k, HIGH); delay(3000); digitalWrite(k, LOW);
  digitalWrite(s, HIGH); delay(1000); digitalWrite(s, LOW);
  digitalWrite(y, HIGH); delay(3000); digitalWrite(y, LOW);
}
