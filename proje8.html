Sıcaklık Sensörü Projesi

Açıklama

Sıcaklık sensörü ile ortam sıcaklığı ölçülür ve seri ekranda gösterilir.

Bağlantılar

  • VCC → 5V
  • GND → GND
  • OUT → A0

Malzemeler

  • Arduino Uno
  • LM35 Sıcaklık Sensörü
  • Jumper Kablolar

Kodlar

int sensor = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int deger = analogRead(sensor);
  float sicaklik = deger * 0.488;
  Serial.println(sicaklik);
  delay(500);
}
