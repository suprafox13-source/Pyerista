Sıcaklık Sensörü

Açıklama

Bu projede sıcaklık sensörü kullanılarak ortam sıcaklığı ölçülür. Belirli bir sıcaklık değerine ulaşıldığında LED veya uyarı sistemi çalıştırılabilir.

Malzemeler

  • Arduino Uno
  • DHT11 veya LM35
  • Jumper kablolar

Kodlar

Kodlar


int ldr = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int isik = analogRead(ldr);
  Serial.print("Işık Seviyesi: ");
  Serial.println(isik);
  delay(500);
}
