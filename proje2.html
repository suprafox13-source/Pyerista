Arduino LED Projesi

Açıklama

Bu projede Arduino kullanarak bir LED’in yakılıp söndürülmesi öğretilmektedir. Yeni başlayanlar için en temel ve anlaşılır projelerden biridir.

Gerekli Malzemeler

  • Arduino Uno
  • LED
  • 220 Ohm Direnç
  • Breadboard
  • Jumper Kablolar

Bağlantılar

LED’in uzun bacağı (anot) Arduino’nun 13. pinine bağlanır. Kısa bacak (katot) direnç üzerinden GND pinine bağlanır.

Arduino Kodu

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
