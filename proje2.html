Proje 2 – Arduino LED Projesi

📘 Proje Açıklaması

Bu projede Arduino kullanarak temel bir LED kontrolü yapılmaktadır. LED belirli aralıklarla yanıp söner. Başlangıç seviyesi için uygundur.

🧰 Gerekli Malzemeler

  • Arduino Uno
  • LED
  • 220Ω Direnç
  • Breadboard
  • Jumper Kablolar

🔌 Bağlantılar

  • LED (+) → Arduino Pin 8
  • LED (-) → 220Ω Direnç → GND

💻 Arduino Kodu

int led = 8;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  digitalWrite(led, HIGH);
  delay(1000);
  digitalWrite(led, LOW);
  delay(1000);
}
