Proje 2 – LED Yakıp Söndürme

Açıklama

Bu projede Arduino kullanılarak bir LED’in belirli aralıklarla yanıp sönmesi sağlanır. Arduino öğrenmeye yeni başlayanlar için en temel ve öğretici projelerden biridir.

Bağlantılar (Neyi Neye Bağlayacağız)

  • LED uzun bacak → Arduino 13. pin
  • LED kısa bacak → 220Ω direnç
  • Direnç → GND

Malzemeler

  • Arduino Uno
  • LED
  • 220Ω direnç
  • Breadboard
  • Jumper kablolar

Kodlar

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
