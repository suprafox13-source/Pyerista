Servo Motor Kontrolü

Açıklama

Bu projede servo motor kullanılarak 0–180 derece arası dönüş sağlanır. Servo motorlar kapı, kol ve mekanizma projelerinde sıkça kullanılır.

Malzemeler

  • Arduino Uno
  • Servo motor
  • Jumper kablolar

Kodlar

Kodlar


int trig = 9;
int echo = 10;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long sure = pulseIn(echo, HIGH);
  long mesafe = sure / 58;

  Serial.print("Mesafe: ");
  Serial.println(mesafe);
  delay(500);
}
