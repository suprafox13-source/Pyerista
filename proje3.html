Buton ile LED Kontrolü

Açıklama

Bu projede bir butona basıldığında LED’in yanması, buton bırakıldığında sönmesi sağlanır. Arduino’da giriş (input) ve çıkış (output) mantığını öğrenmek için ideal bir projedir.

Bağlantılar (Neyi Neye Bağlayacağız)

  • LED uzun bacak → Arduino 8. pin
  • LED kısa bacak → 220Ω direnç → GND
  • Buton bir bacak → Arduino 7. pin
  • Buton diğer bacak → GND

Malzemeler

  • Arduino Uno
  • LED
  • Buton
  • 220Ω direnç
  • Breadboard
  • Jumper kablolar

Kodlar

int led = 8;
int button = 7;

void setup() {
  pinMode(led, OUTPUT);
  pinMode(button, INPUT_PULLUP);
}

void loop() {
  if(digitalRead(button) == LOW){
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}
