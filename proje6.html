Servo Motor Projesi

Açıklama

Servo motor belirli açılara döndürülerek kontrol edilir.

Bağlantılar

  • Kırmızı → 5V
  • Kahverengi → GND
  • Sarı → 9

Malzemeler

  • Arduino Uno
  • Servo Motor
  • Jumper Kablolar

Kodlar

#include 
Servo servo;

void setup() {
  servo.attach(9);
}

void loop() {
  servo.write(0);
  delay(1000);
  servo.write(90);
  delay(1000);
  servo.write(180);
  delay(1000);
}
