LDR Işık Sensörü Projesi

Açıklama

LDR sensörü kullanılarak ortam ışık seviyesi ölçülür ve seri ekrana yazdırılır.

Bağlantılar

  • LDR → A0
  • 10K Direnç → GND

Malzemeler

  • Arduino Uno
  • LDR
  • 10K Direnç
  • Jumper Kablolar

Kodlar

int ldr = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int isik = analogRead(ldr);
  Serial.println(isik);
  delay(500);
}
