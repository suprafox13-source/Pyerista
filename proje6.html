Işık Sensörü (LDR)

Açıklama

Bu projede LDR kullanılarak ortamın aydınlık veya karanlık durumu algılanır. Ortam karardığında LED otomatik olarak yanar.

Malzemeler

  • Arduino Uno
  • LDR
  • LED
  • 220Ω direnç
  • Jumper kablolar

Kodlar

Kodlar


int sensorPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int deger = analogRead(sensorPin);
  float volt = deger * (5.0 / 1023.0);
  float sicaklik = volt * 100;

  Serial.print("Sıcaklık: ");
  Serial.println(sicaklik);
  delay(1000);
}
